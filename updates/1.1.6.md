# What has been updated?

## Changelog - (Added, Fixed, Removed):

- **Added** a new method to prevent running / loading warehouse storages if a warehouse location no longer exists in the config file.
- **Added** a new method to update automatically warehouse storage weights in case they have been changed from config, for example, if when purchased a storage was 200KG but eventually that was too low weight or too high, after server restart, the system will automatically update this storage to the new changed value (weight).
- **Added** the given warehouse key item function to the `server/tp-server_escrow_ignore.lua` file for the developers to access into the given item in case they want to perform any kind of changes.
- **Added** office position(s) to buy warehouses through an office instead of buying directly on the warehouse storage location, the office also has a management section to manage purchased warehouses. The office locations also contain blips, npcs, markers. The npc has an extra feature to have a talk dialog (real voice & subs), similar to RDR with a talking animation when being close to the prompts.
- **Fixed** an issue on open storage key, even if it was not visible, players could still press (hold) and attempt to open main storage (it would throw an error or do no action).
- **Fixed** an issue when attempting to open another storage from a warehouse location, the title was displaying "Buy Warehouse" instead of a text related to access a storage.
- **Improved** most of the events that were been executed for actions such as keys copy, pin generation to a more safe / secure events for cheat prevention.
- **Removed** `PromptFooterRentingDisplay, PromptFooterDisplay, PurchaseDescription, Purchased` options on all `Config.Locations`, those displays are no longer required because of the NUI.
- **Removed** the `AllowKeyholders` and **Keyholders** system in general, the system for the members who can access a warehouse is now **ONLY** through the key item. The `IsWarehousePlayerBased` remains as a feature, this has **NOT** been removed since its for personal storage position.
- **Removed** the `tp_inputs` dependency, we are now using our own NUI dialogs.
- **Removed** the `tpz_menu_base` dependency, we are now using our own NUI instead of a menu.
- **Removed** the `Config.tp_banks` support since you now must be paying the tax through the Office Management NUI at anytime.
- **Removed** the `account` data since you now must be paying the tax through the Office Management NUI at anytime.
